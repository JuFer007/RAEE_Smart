## Flujo de la aplicación

<p align="center">
  <img src="capturas/bienvenida.png" alt="Bienvenida" width="80" style="border-radius: 12px;">
  <span style="font-size:20px">&nbsp;→&nbsp;</span>
  <img src="capturas/login.png" alt="Inicio de sesión" width="80" style="border-radius: 12px;">
  <span style="font-size:20px">&nbsp;→&nbsp;</span>
  <img src="capturas/home.png" alt="Inicio" width="80" style="border-radius: 12px;">
  <span style="font-size:20px">&nbsp;→&nbsp;</span>
  <img src="capturas/tomarFoto.png" alt="Tomar foto" width="80" style="border-radius: 12px;">
  <span style="font-size:20px">&nbsp;→&nbsp;</span>
  <img src="capturas/deteccionDeDispositivo.png" alt="Detección con IA" width="80" style="border-radius: 12px;">
  <span style="font-size:20px">&nbsp;→&nbsp;</span>
  <img src="capturas/elegirPuntoEntrega.png" alt="Elegir punto de entrega" width="80" style="border-radius: 12px;">
  <span style="font-size:20px">&nbsp;→&nbsp;</span>
  <img src="capturas/qrCertificado.png" alt="Certificado QR" width="80" style="border-radius: 12px;">
</p>

1. **Bienvenida**: se muestra la pantalla inicial de la aplicación.
2. **Acceso**: el usuario inicia sesión o crea una cuenta nueva. Si olvidó su contraseña, la recupera ingresando su correo y el código de verificación recibido para establecer una nueva contraseña.
3. **Inicio y menú**: tras entrar, se accede a la pantalla de inicio con el menú de navegación que enlaza reciclaje, puntos de entrega, historial, notificaciones, perfil e información.
4. **Permiso de ubicación**: la app solicita acceso a la ubicación para mostrar los puntos de entrega cercanos.
5. **Reciclaje con IA**: el usuario toma una foto del dispositivo; el sistema lo detecta y lo clasifica automáticamente. Si la clasificación falla, se puede elegir la categoría manualmente.
6. **Punto de entrega**: se selecciona el punto de entrega, se consultan sus horarios y campañas y se registra la entrega.
7. **Certificado digital**: al confirmar la entrega se genera un certificado digital con código QR.
8. **Historial, notificaciones y perfil**: las entregas quedan registradas en el historial; el usuario recibe notificaciones de campañas y horarios y puede administrarlas, así como editar su foto de perfil o cambiar su contraseña.
